# AeroPortals 1.2.4

## Changed

- Detailed teleport logging is now off by default for quieter logs. Set `verbose_logging` to `true` in the server config to capture diagnostics when reporting issues.

## Fixed

- Crew no longer get thrown off the deck on arrival; the safety net now checks every tick for three seconds and no longer gives up at long distances.
- Ships that keep their momentum now arrive stopped and hold still for one second before speeding back up, so the crew can find their footing instead of being left behind in mid-air.
- Physics objects no longer flash in and out of existence while sitting in a portal whose teleport cannot complete; failed teleports now leave the object untouched.
- Ships assembled high in the sky are no longer wrongly refused entry to the Nether and End as "too tall". Ships that fit are slid down into the destination's build range automatically.
- Failed teleports no longer retry several times a second and spam chat; they now wait out the portal cooldown before trying again.
- End portal arrivals now rise above any terrain or builds blocking the landing area instead of refusing to teleport. The same applies to the return trip to the overworld spawn.
