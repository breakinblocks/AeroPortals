# AeroPortals 1.3.2

## Added

- Airships that fall out of the bottom of a dimension are now caught and set down safely. 
- `/aeroportals ships [dimension]` lists the airships in a dimension with their coordinates, including ones the game has set aside because nobody is near them and ones that only exist in the save file.
- `/aeroportals recover <id>` brings an airship from that list to where you are standing, for ships that ended up somewhere nobody can reach.

## Fixed

- Airships no longer go missing after a portal trip when other ships have already used the destination dimension.
- The arrival area is now held open wide enough for the whole ship instead of just the middle of it, so large ships spanning chunks get the same few seconds to settle in that small ones already had.
